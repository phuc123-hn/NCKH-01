Cách tính Anomaly Score: Mỗi flag cộng điểm theo mức độ. Tổng điểm > ngưỡng → cảnh báo.
Kết hợp với ML confidence: nếu ML cao + Anomaly Score cao → chắc chắn malware.
Nếu ML cao nhưng Anomaly Score thấp → cần xem xét thêm (false positive potential).

Thay đổi nhiều → dễ bị domain shift ảnh hưởng
Công thức: stability(feat_i) = 1 − std(SHAP_i across subsets) / mean(|SHAP_i|)
Ý nghĩa: Feature có stability cao → không bị ảnh hưởng bởi phân phối data cụ thể → robust hơn với malware mới.
Ứng dụng: CMS chỉ dùng feature có stability > 0.7 thay vì chỉ dùng top mean |SHAP|.
Robustness Test — F1 theo mức noise
Mô phỏng malware biến thể (obfuscation, packing) bằng Gaussian noise. Model giảm chậm = robust hơn
LightGBM
XGBoost
RandomForest
Cách đọc biểu đồ: Trục X là mức noise σ (0 = không nhiễu, 2.0 = nhiễu cực lớn).
Trục Y là F1 score. Model giảm chậm nhất = robust nhất với malware chưa từng thấy.
Kết quả kỳ vọng: LightGBM và XGBoost robust hơn RandomForest vì gradient boosting tổng hợp nhiều weak learner, ít bị ảnh hưởng bởi noise trên từng feature.
